# User Guide for NE Healthcare App

## 1. Introduction

This guide explains how to use the NE Healthcare App. It is intended for end users, support teams, and stakeholders who need a clear overview of the application's features and workflows.

### Purpose

- Describe the main functions of the application.
- Help users complete common tasks.
- Provide basic troubleshooting guidance.

### Scope

This document covers:

- User access and sign-in
- Main navigation areas
- Core user tasks
- Common issues and support guidance

## 2. Intended Audience

This document is written for:

- Patients or end users
- Healthcare staff using the application
- Administrators or support personnel

## 3. Prerequisites

Before using the application, make sure the following requirements are met:

- A valid user account is available.
- Internet access is stable.
- A supported browser or mobile device is being used.
- Required permissions have been granted.

## 4. Getting Started

### Accessing the Application

Application URL: <https://ne.jayasivabaskar.com>

1. Open <https://ne.jayasivabaskar.com> in your browser or launch the mobile app.
2. Enter your username or email address.
3. Enter your password.
4. Select **Sign In**.

### First-Time Login

If you are logging in for the first time:

1. Use the credentials provided by the administrator.
2. Change your password if prompted.
3. Review and accept any required terms or policies.

## 5. Application Overview

### Main Sections

The application may include the following sections:

- Dashboard
- Appointments
- Patient Records
- Notifications
- Profile or Account Settings

### Navigation

Users can move between sections using the main menu, navigation bar, or dashboard shortcuts.

## 6. Key Features and Tasks

### View Dashboard

The dashboard provides a summary of important information such as upcoming appointments, recent activity, alerts, or quick links.

### Manage Appointments

Users can typically:

- View scheduled appointments
- Book a new appointment
- Reschedule an existing appointment
- Cancel an appointment if permitted

### View Patient Information

Depending on user role and permissions, users may be able to:

- View patient details
- Review medical history
- Check prescriptions or reports

### Update Profile

Users can update personal account details such as:

- Name
- Contact information
- Password
- Notification preferences

## 7. Common Workflow Example

### Book an Appointment

1. Sign in to the application.
2. Open the **Appointments** section.
3. Select **Book Appointment**.
4. Choose the required date, time, and provider.
5. Confirm the booking.
6. Review the confirmation message.

## 8. Troubleshooting

### Unable to Sign In

If a user cannot sign in:

- Verify the username and password.
- Check whether the account is active.
- Use the password reset option if available.
- Contact support if the issue continues.

### Application Not Loading

If the application does not load properly:

- Refresh the page.
- Check the internet connection.
- Clear browser cache if using a web version.
- Try another supported browser or device.

## 9. Frequently Asked Questions

### How do I reset my password?

Use the **Forgot Password** option on the sign-in page and follow the instructions.

### How do I update my personal details?

Open the **Profile** or **Settings** section and save the required changes.
